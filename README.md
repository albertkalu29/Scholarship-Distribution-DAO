# 🎓 Scholarship Distribution DAO

A decentralized autonomous organization (DAO) for managing scholarship applications and distributions on the Stacks blockchain. Students can apply for scholarships on-chain, and committee members vote to approve or reject applications before funds are distributed.

## ✨ Features

- 📝 **On-chain Applications**: Students submit scholarship applications directly to the blockchain
- 🗳️ **Committee Voting**: Designated committee members vote on applications
- 💰 **Automated Distribution**: Approved scholarships are distributed automatically
- 📊 **Transparent Process**: All votes and decisions are recorded on-chain
- 🔒 **Secure Governance**: Only authorized committee members can vote
- 📈 **Application History**: Track all applications per student

## 🚀 Getting Started

### Prerequisites

- [Clarinet](https://github.com/hirosystems/clarinet) installed
